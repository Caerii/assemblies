# Exploratory probes, 2026-10-10: a sleep gate fixed at birth

Every probe here is EXPLORATORY: not registered, run on twenty brains with seeds
outside every registration's (subjects 980-999, references 960-979), at cells
earlier registrations judged, and reported only to explain why a registration
was designed as it was, never to support a claim. They are disclosed in
[PREREG_refraction_memory.md](../../PREREG_refraction_memory.md).

| `probe_setpoint.py` -> `probe_setpoint.log` | A sleep gate with NO reference brains: each brain fixes its contrast gate once, before it learns anything, at 1.02 x the largest contrast its own EMPTY network's dreams reach (300 dreams). Against Amendment 54's median-of-reference-brains rule, on a healthy U = 10 store, a standard U = 50 store and a comparator U = 100 store, (10000, 75, 0.48) | IT WORKS, WITH A THIN MARGIN. Empty networks dream at contrast 1.330 (brain maxima 1.349-1.357); learning a healthy store raises that only slightly (1.347; maxima 1.366-1.374, median 1.369), so each brain's healthy-store maximum lies 0.3-1.2% BELOW its own birth set point (1.376-1.384). Healthy U = 10: 1.000, nothing removed under both gates. Standard U = 50: 0.025 -> 0.766 (reference median, 4.2% removed) vs 0.779 (own set point, 4.9%). Comparator U = 100: 0.249 -> 0.670 (1.5%) vs 0.712 (3.0%), lowest brain 0.59 vs 0.63, none collapsed. The set point sits slightly lower than the reference rule, so it does a little more repair at a little more cost; its safety margin on a healthy store is about 1%, set by 1.02 | a registered set-point gate |
