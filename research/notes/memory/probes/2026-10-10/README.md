# Exploratory probes, 2026-10-10: a sleep gate fixed at birth

Every probe here is EXPLORATORY: not registered, run on twenty brains with seeds
outside every registration's (subjects 980-999, references 960-979), at cells
earlier registrations judged, and reported only to explain why a registration
was designed as it was, never to support a claim. They are disclosed in
[PREREG_refraction_memory.md](../../PREREG_refraction_memory.md).

| `probe_setpoint.py` -> `probe_setpoint.log` | A sleep gate with NO reference brains: each brain fixes its contrast gate once, before it learns anything, at 1.02 x the largest contrast its own EMPTY network's dreams reach (300 dreams). Against Amendment 54's median-of-reference-brains rule, on a healthy U = 10 store, a standard U = 50 store and a comparator U = 100 store, (10000, 75, 0.48) | IT WORKS, WITH A THIN MARGIN. Empty networks dream at contrast 1.330 (brain maxima 1.349-1.357); learning a healthy store raises that only slightly (1.347; maxima 1.366-1.374, median 1.369), so each brain's healthy-store maximum lies 0.3-1.2% BELOW its own birth set point (1.376-1.384). Healthy U = 10: 1.000, nothing removed under both gates. Standard U = 50: 0.025 -> 0.766 (reference median, 4.2% removed) vs 0.779 (own set point, 4.9%). Comparator U = 100: 0.249 -> 0.670 (1.5%) vs 0.712 (3.0%), lowest brain 0.59 vs 0.63, none collapsed. The set point sits slightly lower than the reference rule, so it does a little more repair at a little more cost; its safety margin on a healthy store is about 1%, set by 1.02 | a registered set-point gate |
| `probe_dreams.py` -> `probe_dreams.log` | READ THE DREAMS: sleep's free dynamics from noise (12 steps, nothing unlearned), each step decoded with the replay read-out (best-overlapping stored token; settled if >= 0.5; faithful if consecutive tokens of one sequence; splice if the successor of another occurrence of the current word; loop if a token revisited). 200 dreams x 20 brains on a healthy U = 10 store, a captured U = 50 store and the same store after 300 episodes of median-gated sleep, (10000, 75, 0.48); transcripts of the brain the capture hurt most | HEALTHY DREAMS ARE EMPTY: no step settles (best overlap 0.05-0.08, the best of ~2000 tokens by chance), contrast 1.347. A healthy token store has no pits a random state falls into: its memories are paths reached only from a cue. CAPTURED DREAMS ARE ONE RECURRING DREAM: 81% of steps sit exactly on stored tokens (overlap 1.00), contrast 6.7 (p99 20.0, about w_max = 20: as if the winners' input synapses were saturated), ~9 distinct tokens per dream, 36% of transitions faithful (runs of ~3, up to 9), loops 6%, splices at a shared word only 0.4% (the fan does NOT drive dreams). In the worst brain four dreams from four random starts fall onto the SAME track and follow it word for word: a chain through the ends of successive sequences IN WRITE ORDER (155 -> 163 -> 169 -> 174 -> 179 -> 212 -> 213 -> 214 -> 215), deepest (contrast ~20) in the older part, 2-4 at the newer edge -- the capture cascade traced as a dream; jumps between sequences often keep the position (8 -> 8, 9 -> 9, 13 -> 13), suggesting the captured links bind along a position signature (untested). AFTER ONE NIGHT (4.2% of counts removed; replay 0.025 -> 0.766) the dreams are empty again: no settled step, contrast 1.362, best overlaps 0.07-0.15 -- slightly above healthy, a faint scar of the erased track | a position-signature test; a lifetime run |
