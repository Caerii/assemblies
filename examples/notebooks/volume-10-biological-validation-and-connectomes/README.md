# Volume 10: Biological Validation And Connectomes

This volume asks how the assembly calculus might meet biological data.

It should distinguish parameter alignment, simulation on mapped graphs, neural
recording comparisons, and full biological claims. Those are different evidence
levels.

## Notebooks

- `01_biological_validation_map.ipynb`: inspect the files and quantities that
  define the biological-validation and connectome track.
