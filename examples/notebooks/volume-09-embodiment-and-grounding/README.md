# Volume 9: Embodiment And Grounding

This volume is for sensors, actions, grounded words, and future robot tasks.

Most of this track is not yet a package-backed robot loop. The notebooks should
therefore start as interface and evidence maps: what would need to be encoded,
what would need to be decoded, and which parts are already supported by assembly
operations.

## Notebooks

- `01_grounding_interface_map.ipynb`: map object, action, word, and social
  curriculum tasks to the existing evidence and missing interfaces.

## Future Notebooks

- continuous observation to assembly encoder stubs
- assembly to action readout stubs
- affordance binding diagnostics
- embodied two-word command probes
- social turn-taking task maps
- Isaac Lab integration checks once the loop exists

This volume should be honest about the gap between toy grounding and embodied
control.
