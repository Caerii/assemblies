# Volume 7: Control, Circuits, And Runtime

This volume treats assembly operations as scheduled protocols.

Instead of asking only what an operation returns, it asks which projection
fibers are active, which are inhibited, and how control changes the trajectory.

## Notebooks

- `01_fiber_circuit_gating.ipynb`: use `FiberCircuit` to route a cue through a
  three-area circuit and inspect which fibers were active at each step.

## Future Notebooks
