# Volume 6: Binding, Composition, And Interference

This volume asks what it costs to compose assemblies.

The first binding notebooks in Volume 1 show that merge can create a target
assembly. This volume should grow that into reliability curves, source-response
diagnostics, interference tests, and capacity limits.

## Notebooks

- `01_binding_diagnostics.ipynb`: form a two-source binding and inspect the
  target trace, source-response overlaps, and the diagnostics that should grow
  into composition experiments.

## Future Notebooks

- many bound objects in one target area
- compositional interference under shared sources
- source-response reliability across seeds
- role binding and filler binding side by side
- merge versus association as two different protocols

Keep the claims narrow: composition is useful only in regimes where the target
is stable, recoverable, and distinguishable from other bindings.
